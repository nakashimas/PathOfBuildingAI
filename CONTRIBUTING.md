# Contributing to Path of Building AI

Thank you for your interest in contributing!  
This project is small but open to improvements, bug fixes, and documentation updates.

## Workflow

1. Create a new branch from `main`.
2. Make your changes.
3. Run tests or check that it works.
4. Commit and push your branch.
5. Open a Pull Request (PR) to `main`.

## Coding Style

- Follow [PEP8](https://pep8.org/) (for Python)
- Use clear and descriptive variable names.
- Keep functions short and focused.

## Optional: VS Code Settings

To ensure consistent formatting, add the following to your VS Code settings:

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,

  "[python]": {
    "editor.defaultFormatter": "ms-python.black-formatter"
  }
}
```

These settings will:

- Use Prettier for most files.
- Use Black for Python files.
- Automatically format code when you save (Ctrl + S).

If you have any questions, please open an issue.
